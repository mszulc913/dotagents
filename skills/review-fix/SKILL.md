# Code review with automatic fixes
Run the /review skill, but do not ask the operator in Triage or Elaborate. Decide each finding yourself: fix each finding that has a real effect, and skip theoretical and low-value ones. Choose the fix for each finding yourself, then run Implement. Findings can overlap or depend on each other, so choose fixes that do not conflict.
